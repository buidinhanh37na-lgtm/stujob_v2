# Stujob — Nền tảng việc làm sinh viên

Dự án **Stujob** — nền tảng kết nối sinh viên với việc làm bán thời gian.

## 🏗️ Kiến trúc

- **Monorepo**: pnpm workspace
- **Backend**: Node.js + Express + Prisma + MySQL
- **Frontend**: Next.js 14 + React + TypeScript + Tailwind CSS
- **Shared packages**: `@stujob/types`, `@stujob/validation`
